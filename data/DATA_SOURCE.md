# 데이터 출처 및 수집 방법

## 1. 전력수요 (주 데이터)

- **데이터명**: 한국전력거래소_시간별 전국 전력수요량
- **제공기관**: 한국전력거래소 (KPX), 관리부서 전사AX총괄팀
- **출처 URL**: https://www.data.go.kr/data/15065266/fileData.do
- **수집일**: 2026-09-02
- **수집 방법**: 공공데이터포털 파일데이터 CSV 직접 다운로드 (로그인 불필요).
  현재 파일 1개 + '주기성 과거 데이터' 목록에서 과거 연도 파일 5개를 내려받아 병합.
- **라이선스**: 이용허락범위 제한 없음 / 비용 무료
- **기간**: 2013-01-01 ~ 2025-12-31
- **단위**: MWh (육지 + 제주 합계)
- **원본 구조**: `날짜, 1시, 2시, ... 24시` (wide format), 인코딩 EUC-KR(CP949)
- **비고**: 제공기관 설명에 따르면 수요예측 목적의 발전단 기준 잠정치.

## 2. 기온·일사 (보조 데이터)

- **데이터명**: 기상청_지상(종관, ASOS) 일자료 조회서비스
- **제공기관**: 기상청 (국가기후데이터센터)
- **출처 URL**: https://www.data.go.kr/data/15059093/openapi.do
- **엔드포인트**: `https://apis.data.go.kr/1360000/AsosDalyInfoService/getWthrDataList`
- **관측지점**: 서울 (지점번호 108)
- **기간**: 2013-01-01 ~ 2025-12-31 (4,748일, 전력수요와 정확히 일치)
- **활용신청**: 2026-09-02 승인, 개발계정, 만료예정 2028-09-02, 일 10,000건
- **수집일**: 2026-09-03
- **수집 방법**: OpenAPI를 연도 단위(numOfRows=400)로 13회 호출해 CSV로 저장.
  분석 환경의 네트워크 정책상 apis.data.go.kr 직접 호출이 차단되어
  브라우저에서 수집했다. 스크립트는 `src/collect_asos.js` 참고.
- **수집 항목**: tm(일자), avgTa/minTa/maxTa(평균·최저·최고기온 °C),
  sumRn(일강수량 mm), avgRhm(평균습도 %), avgWs(평균풍속 m/s),
  sumGsr(합계 일사량 MJ/m²), sumSsHr(합계 일조시간 h)
- **주의**: API 키는 개인 발급분이므로 저장소에 커밋하지 않는다.
  `.env`(gitignore 대상) 또는 환경변수 `KMA_API_KEY`로 주입한다.

### 기상 데이터 결측 처리

| 항목 | 결측 일수 | 처리 |
|---|---|---|
| avgTa (평균기온) | 0 | - |
| minTa / maxTa | 각 1 | 분석에 평균기온을 주로 쓰므로 그대로 둠 |
| sumRn (강수량) | 2,852 | **결측이 아니라 '강수 없음'** → 0.0으로 대체 |
| avgRhm (습도) | 0 | - |
| avgWs (풍속) | 8 | NaN 유지 (해당일 제외 후 계산) |
| sumGsr (일사량) | 30 | NaN 유지 |
| sumSsHr (일조시간) | 17 | NaN 유지 |

강수량의 공란이 전체의 60%인데, 이를 결측으로 보고 삭제하면 맑은 날이 전부
사라진다. 기상청 규정상 강수 현상이 없으면 값을 기록하지 않으므로 0으로 해석하는
것이 옳다. 결측 처리 기준을 잘못 잡으면 데이터의 절반을 잃는 사례로 리포트에 기록한다.

## 3. 시각 규정

원본의 `h시` 컬럼은 시간대의 끝(hour-ending)으로 해석했다.
따라서 `datetime = 날짜 + h시간`이며, `24시`는 다음 날 00:00에 해당한다.
